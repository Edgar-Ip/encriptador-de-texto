# Encriptador/Desencriptador de Texto

## Este es un encriptador y desencriptador de texto desarrollado con HTML, CSS y JavaScript. Permite ingresar un mensaje, encriptarlo o desencriptarlo con un algoritmo simple y copiar el resultado al portapapeles.

### 🛠️ Tecnologías utilizadas
- HTML (estructura del sitio)
  
- CSS (estilos y diseño, con enfoque responsivo)
  
- JavaScript (lógica de encriptación y eventos)

  
#### 📌 Funcionalidades
- ✅ Encripta texto ingresado por el usuario.
- ✅ Desencripta el texto previamente encriptado.
- ✅ Permite copiar el resultado con un botón y pegarlo con Ctrl + V.
- ✅ Diseño responsivo, adaptado a dispositivos móviles y escritorio.

#### Uso

- Para poder encriptar o desencriptar un mensaje, este no debe contener caracteres especiales, mayúsculas o acentos, de lo contrario, no se podrá aplicar la función de "Encriptar" o "Desencriptar".
  

#### 📄 Estructura del proyecto
El proyecto consta de los siguientes archivos:
- 📌 index.html - Interfaz de usuario.
- 📌 styles.css - Estilos y diseño responsivo.
- 📌 app.js - Lógica de encriptación y eventos.


### 🚀 Cómo ejecutar el proyecto
1- Descarga o clona el repositorio.
2- Abre el archivo index.html en un navegador.
3- Ingresa un texto y utiliza los botones para encriptar, desencriptar y copiar.
